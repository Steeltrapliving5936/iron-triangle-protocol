# docs/assets — release assets

Generated, committed artifacts used by the README and the future GitHub repository page. Regeneration is offline and deterministic given the same tree; `verify` is stdlib-only and runs in CI.

| File | What it is | Generated by |
|---|---|---|
| `demo-terminal.gif` | Real terminal recording of the README quick start + hygiene gates (unittest discovery, config doctor, sanitization scan, generated-skill check) | `python3 scripts/make_release_assets.py gif` |
| `demo/session.cast.jsonl` | Capture source for the GIF: header plus timestamped output events. Output lines are captured bytes from real executions; prompt lines are rendered by the recorder (same convention as scripted terminal-recording tools) | `python3 scripts/make_release_assets.py record` |
| `social-preview.png` | 1280×640 GitHub social preview | `python3 scripts/make_release_assets.py social` |
| `social-preview.svg` | Editable SVG source of the social preview | same |

## Reproducing

```bash
# recording: needs a clean checkout; runs quick-start commands in an isolated
# temp HOME/clone — never touches your real HOME, runtime config, or services
python3 scripts/make_release_assets.py record   # macOS/Linux, stdlib only
python3 scripts/make_release_assets.py gif      # needs macOS qlmanage + ffmpeg
python3 scripts/make_release_assets.py social   # needs macOS qlmanage
python3 scripts/make_release_assets.py verify   # stdlib only, CI-safe
```

The recorder refuses to overwrite an existing cast; delete `demo/session.cast.jsonl` first when re-recording on purpose.

## Hygiene rules enforced on these assets

- `verify` re-runs the sanitizer rules over every captured output line in the cast (zero hits required).
- GIF must be valid GIF89a, exactly 860×540, ≥10 frames, 5–120 s, <2 MiB.
- Social preview PNG must be exactly 1280×640 and <1 MiB.
- Terminal content shows only generic paths (`demo@cleanroom`, temp-dir HOME); no user names, session ids, tokens, or internal hosts.
